# OpenSpec: gitlab-token-updater

## Purpose

Track specifications, design proposals, and change management tasks for the repository using OpenSpec.

## Ownership

Owns `openspec/config.yaml`, `openspec/specs/`, and active/archived changes under `openspec/changes/`.

## Local Contracts

- Follow OpenSpec schema (`spec-driven`).
- Proposals, delta specs, and tasks are located under `openspec/changes/<change-id>/`.
- Completed changes are archived to `openspec/changes/archive/`.

## Work Guidance

- Use openspec skills (`openspec-propose`, `openspec-apply-change`, `openspec-sync-specs`, `openspec-archive-change`).

## Verification

- Schema adherence against `openspec/config.yaml`.
